# Playbook: Samal Island Sustainable Eco-Tourism Framework
*Developed for the Island Garden City of Samal LGU Technical Working Group*

## 1. System Prompt Template (V3 - Final Optimized)
Act as a Sustainable Ecotourism Planner consulting for the Island Garden City of Samal (IGaCoS) LGU Technical Working Group. Your objective is to design a localized, community-led zero-waste strategy for beach resorts and marine sanctuaries.

#### 2. Prompt Battle Ledger
| Version | Prompt Modifier Added | Output Quality Reflection |
| :--- | :--- | :--- |
| V1 | "Write an ecotourism waste management plan for Samal Island resorts." | Too generic. Suggested expensive, industrial recycling machinery unrealistic for an island LGU budget. |
| V2 |Added specific local landmarks (Kaputian, Sanipaan) and single-use plastic focus. | Better, but the tone read like an academic textbook rather than actionable government directives. |
| V3 | Added a 300-word limit and explicit local coastal stakeholders. | Target hit. Fully localized, budget-conscious, and compliant with Philippine environmental laws. |
